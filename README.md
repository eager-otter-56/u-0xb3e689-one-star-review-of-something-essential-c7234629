# One-Star Review of Something Essential

A tiny Python program that writes one deadpan one-star review of sleep —
an everyday essential nobody can opt out of — to `entry.txt` in
`MAKEFUN_OUTPUT_DIR` (default `/output`). The review is a single line of
at most 160 characters: eight hours taken nightly, non-negotiable, impossible
to bank, and absent on the one night it is begged for.

Run it with:

```sh
python3 main.py
```
